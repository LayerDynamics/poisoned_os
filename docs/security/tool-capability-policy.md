# PoisonedOS tool capability policy

Tool capabilities are explicit strings reviewed with each adapter and package. Read/observe capabilities may emit bounded raw or derived evidence; write, transmit, replay, emulation, bus power, HID execution, and deletion capabilities are separate and require a fresh session authorization decision plus exact-target confirmation.

Every adapter must enforce role, classroom, hardware, regional radio, resource ownership, and evidence-redaction policy on the device immediately before execution. Browser state and cached approvals are advisory only. Stop, disconnect, lock, policy change, or resource loss terminates the active operation and leaves the peripheral in its safe state.

Catalog entries must declare a non-destructive sample, bounded parameters, output/evidence types, and safety notes. Unsupported hardware, malformed input, oversized input, stale package metadata, revoked signer, or missing adapter causes fail-closed quarantine.
