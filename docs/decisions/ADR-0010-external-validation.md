# ADR-0010: External Validation Claims

## Status

Accepted for V1.

## Decision

No external laboratory, forensic, or security certification is commissioned for the V1 release. V1 may describe implemented integrity verification, signed artifacts, and reproducible evidence digests, but it does not claim forensic certification, admissible evidence, court-ready output, or equivalent external validation.

## Evidence required to reopen

Any future external-validation claim requires an independent provider, exact released artifact/version, scope, limitations, publication reference, renewal owner, and a release-gate test that rejects stale or mismatched reports.
