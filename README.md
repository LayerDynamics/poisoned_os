# PoisonedOS for the Flipper_Zero

A Custom OS that focuses on ease of use, user custumization ability, robust built in tools and data for security/education, and specifically targeting cyber security professionals that work in the field.

Has a legit file_system, Works tightly with a web based dashboard that the users access on their phones for direct control of the device, all outputs and apps directly from the browser, will be more professional and allow for customization and ui changes easily through the same dashboard
